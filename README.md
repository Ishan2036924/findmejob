# CareerForge

Working name. AI-native career platform — candid profile assessment, personalized roadmap, verified job aggregation, and on-click tailored bundle (resume, cover letter, interview prep, outreach, company brief) per job.

**Status:** pre-build. Architecture and research phase. See `CLAUDE.md` for project state, `.claude/NOTES.md` for stable knowledge, `.claude/LOG.md` for decision log.

**Stack:** Next.js (App Router) + Supabase + Vercel AI Gateway + Tectonic (LaTeX).
